# Wayfare

**Every trip, on one map.** Wayfare is an AI travel companion that plans your days
**door-to-door** — real routes, honest peso cost ranges, and a reason behind every
stop — then draws the whole day on a **live, cinematic 3D map** and walks it with you.

<p align="center"><em>Expo / React Native (web + mobile) · Fastify API · shared TypeScript types · MapLibre 3D</em></p>

---

## ✨ What's inside

A complete, navigable app — **~30 screens**, every one a glass sheet over the live
night map (the **Map-first** design, Approach 2 of [`design/app-preview.html`](./design/app-preview.html)).

| Area | Screens |
| --- | --- |
| **Entry & auth** | Splash (route-W logo) · Onboarding · Login · Register · Forgot |
| **Tabs** | Home (live map) · Trips · Alerts · Profile — circular floating dock |
| **Create** | Start method · Chat + live map · Basics · Vibe · Interests · Review · Generating (3D companion) · Import |
| **Propose & edit** | Proposals · Customize · Recommended places · Swap · Confirm |
| **Live trip** | Trip Overview · Day (schedule slider) · Activity detail · Place detail · Route map + in-app immersive nav |
| **Settings** | Calendar · Availability / work blocks · Reminders |

**Real 3D map.** A keyless [OpenFreeMap](https://openfreemap.org) dark vector basemap
with Google-style **3D building extrusions**, camera tilt, **compass rotation**, zoom,
and tappable pins. Buildings correctly **occlude the roads behind them** by camera
angle. Walking routes come from **OSRM**, geocoding from **Nominatim** — all free.

**Playful Adventure design.** A cinematic **night** palette led by grape violet, with
**Anton** (display) + **Fredoka** (body), night-glass sheets, marigold routes, mint
success, and the coral-tipped **route-W** logo. See the full [**brand kit**](./design/brand-kit.html).

**Coherent, AI-built itineraries.** Plans start from a home base, respect a work block,
route BGC → Old Manila and back, and carry per-day travel modes, ₱ ranges, notes, and
map pins — generated by OpenAI and enriched with Google Places photos/reviews (cached
compliantly; see [`docs/places-caching-design.md`](./docs/places-caching-design.md)).

## 🚀 Getting started

**Prerequisites:** Node 20+ · the Expo toolchain (via `npx`). For a native Android
build: JDK 17 + the Android SDK.

From the repo root (a small npm-workspace with convenience scripts):

```bash
npm run server      # Fastify API on http://localhost:4100  (server/ — needs its .env)
npm run web         # Expo web on http://localhost:8081
npm run app         # Expo dev server (press a / i, or scan the QR for a device)
```

Or per package:

```bash
cd app && npm install && npm run web
cd server && npm install && npm run dev
```

`preweb`/`prestart`/`postinstall` automatically copy the MapLibre worker into
`app/public/` — under Metro the default worker URL 404s, which is what caused the
old "AJAX error" on map screens.

### Environment

- **App** (`app/.env.local`, bundled & public — no secrets): the map renders keyless
  by default. Optional `EXPO_PUBLIC_MAP_STYLE_URL` / `EXPO_PUBLIC_PMTILES_URL` /
  `EXPO_PUBLIC_MAP_RASTER=1`. See [`app/.env.example`](./app/.env.example).
- **Server** (`server/.env`, **gitignored**): `GOOGLE_MAPS_API_KEY` (Places API New),
  `OPENAI_API_KEY`, and optional Firebase service account. No keys → offline stubs.
  See [`server/.env.example`](./server/.env.example) and [`docs/maps-setup.md`](./docs/maps-setup.md).

### Tests

```bash
cd app
npx playwright install chromium   # once (or set $PW_CHROMIUM to a Chrome binary)
npm run e2e                        # walks the whole app, one screen at a time, errors + screenshots
```

## 🗺️ Data model

```
Itinerary
 ├─ dateRange, partySize, currency, homeBase, assumptions
 ├─ proposals: Proposal[]          (alternative week-shapes)
 │   └─ days: Day[]                (theme, timeWindow, comingFrom→destination,
 │                                  detailedPlan, travelMode, cost, notes, location,
 │                                  activities: Activity[] {time, where, lat/lng, placeId})
 └─ places: Place[]                (name, area, lat/lng, placeId, why)
```

Document-shaped for Firestore. Types live in [`packages/shared`](./packages/shared)
and are mirrored in `app/src/lib/types.ts` (the app duplicates them to avoid Metro
monorepo config).
