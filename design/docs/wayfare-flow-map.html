01

The shape of it

Wayfare turns a starting place, a destination, and a purpose into a day-by-day plan. You begin one of three ways — chat with the AI, build it by hand, or import a spreadsheet — and the AI fills in the timings, cost ranges, travel modes, and map pins. On the road it runs your live day: the next stop, how far it is from your GPS, arrival check-ins, and reminders — all scheduled around the hours you've blocked for work and other commitments.

Data model
Itinerary — trip, currency, home base
 ├─ Proposal[] — style variants
 │   └─ Day[] — date · theme · stops
 │      └─ Stop · time · plan · cost · geo
 ├─ Place[] — maps catalog
 └─ Commitment[] — work / blocks
One source, two clients

The web app and the mobile app talk to the same Fastify API. Every itinerary is stored under an ownerId (the signed-in account), so a spreadsheet imported on the web appears on the phone with no extra work. Storage is JSON today, Firestore later — behind one Repo seam. AI generation and map geocoding happen server-side; the OpenAI key never ships in a client.

08

Recommended build order

This is a real sequence — each step unblocks the next.

  1. Server: save + import.
    Wire POST /api/itineraries and POST /api/imports (CSV/XLSX → our shape). Testable today against the real docs/*.xlsx — no API key needed.
  2. Server: AI generate.
    POST /api/generate calling OpenAI with the key in a server .env; validate against the Day schema; geocode stops.
  3. Fill the P1 gap pages.
    Onboarding 2–3, permissions, empty state, place search, stop/day editor, import upload/error, generation retry.
  4. Expo: read paths.
    Home → Proposals → Trip → Day → Route Map / Place Detail, all reading the live API by account.
  5. Expo: live day.
    GPS distance to next stop, arrival check-in, cancel-next reflow, and the Google Maps embed pin.
  6. Reminders.
    Schedule local notifications from each itinerary at the configured intervals, respecting work blocks and stay-up-late.
  7. Motion pass.
    Port the cinematic success + confirm sheets to Reanimated/Moti; wire confirmations to every destructive action.
