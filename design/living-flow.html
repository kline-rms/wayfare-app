What I changed in the structure

  • 1
    Logo is a 3D place + walking persona, not a globe. Splash and the 3D layer both use it, so the brand mark and the hero match.
  • 2
    Proposals upgraded to the app-ref-1 “color worlds” — each of the 3 is its own gradient card with giant type + “View plan.” This is the “see 3 proposals and edit them” moment, now impossible to miss.
  • 3
    New screen: Live day · next stop (cinematic night). Splits the boring day list into a heads-up companion view with GPS distance/ETA and a reminder Skip control.
  • 4
    Route Map is no longer an orphan. It’s now the cinematic night map (footprints + glowing marker) and is reached from the day view’s “Open live route” button — a real entry point.
  • 5
    The green orb is retired. One amber companion mascot now carries chat, generating, tips, and reminders — a single recurring character instead of a stray blob.
  • 6
    Reminders gained a Skip / extend row (+15m), matching your “skip this part and extend the time” request.
Navigation structure is unchanged — same 4 tabs, same create → propose → live spine. Every change is additive or a reskin.
